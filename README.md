# Public-homeassistant-repo

A collection of Home Assistant automations, configurations, and dashboard cards.  
These configurations are designed to automate and optimize home energy management, lighting, and smart home integrations.

## 🎯 Purpose

The goal of this repository is to provide a central place for useful and reusable Home Assistant configurations.  
All automations have been tested, but always validate in a test environment before using them in production.

## 📂 Contents

* **Zaptec** – Solar-based EV charging automations for the Zaptec Go 2

## 🔧 Prerequisites

* [Home Assistant](https://www.home-assistant.io/) (2025.7 or newer)
* Relevant integrations installed via [HACS](https://hacs.xyz/) where noted per topic

## 🚀 Usage

1. Clone or download the repository:

   ```
   git clone https://github.com/GrasshopperNL/Public-homeassistant-repo.git
   ```

2. Navigate to the relevant folder and follow the instructions in the README.md of that folder.

## ⚠️ Disclaimer

All configurations are provided as-is.  
Always review and test before applying to your production environment.  
Placeholders like `YOUR_CHARGER_NAME` must be replaced with values specific to your own setup.
